# Hesba Dashboard Mobile

## الدور داخل المستودع
تطبيق الموبايل الخاص بمنصة Hesba لسيناريوهات التشغيل اليومية وإدارة المنصة على الهاتف.

## تقنيات مؤكدة من المشروع
- Framework: `Expo` + `React Native`
- Navigation/Routing: `expo-router` (مع `@react-navigation/*`)
- Language: `TypeScript`
- Data Fetching: `@tanstack/react-query`
- State Management: `zustand`
- i18n: `i18next` + `react-i18next`
- Styling: `nativewind`
- Networking/Auth-related libs: `axios`, `expo-secure-store`

## أماكن الكود الأساسية
- `src/app`: الشاشات والمسارات
- `src/features`: منطق الوحدات
- `src/lib`: API/config/helpers
- `src/stores`: إدارة الحالة
- `src/i18n`: الترجمة

## مراجع محلية
