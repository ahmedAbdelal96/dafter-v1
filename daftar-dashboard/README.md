# Hesba Dashboard (Web)

## الدور داخل المستودع
واجهة الويب الإدارية/التشغيلية الخاصة بمنصة Hesba.

## تقنيات مؤكدة من المشروع
- Framework: `Next.js` (App Router)
- Runtime: `React`
- Language: `TypeScript`
- i18n: `next-intl`
- Data Fetching: `@tanstack/react-query`
- State Management: `zustand`
- HTTP Client: `axios`
- Styling: `Tailwind CSS`

## أماكن الكود الأساسية
- `src/app`: تعريف الصفحات والمسارات
- `src/features`: منطق وواجهات كل Feature
- `src/lib`: API/client utilities وحراس/مساعدات
- `src/config`: إعدادات المسارات والتنقل
- `messages`: ملفات الترجمة
- `docs`: وثائق الواجهة النشطة
