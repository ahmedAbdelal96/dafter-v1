# Backend Plan (Draft Under Reconstruction)

هذه الوثيقة كانت تحتوي خطة قديمة غير متسقة في التسمية والترميز، لذلك تم تقليصها مؤقتًا.

## الغرض الحالي
تحديد مكان تجميع خطة التنفيذ الخلفية بشكل موثوق لاحقًا.

## ما يجب توثيقه لاحقًا
- خريطة Modules الفعلية في `src/modules`
- قواعد Layering المعتمدة في المشروع
- معايير API responses والأخطاء
- قواعد الأمان (guards/permissions/subscription constraints)
- مسار التحقق والاختبارات قبل الدمج

## مصادر الحقيقة الحالية
- `src/`
- `prisma/`
- `app.module.ts`
