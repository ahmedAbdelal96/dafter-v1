# Hesba

Hesba هو مستودع منصة متعددة التطبيقات يضم واجهات الويب والموبايل مع واجهة API.

## هيكل المستودع
- `hesba-api-v1`: خدمة الـ API الخلفية.
- `hesba-dashboard`: لوحة التحكم (Web).
- `hesba-dashboard-mobile`: تطبيق الموبايل.
- `docs`: وثائق تشغيل/متابعة عامة (بعضها قيد إعادة البناء).
- `study-docs`: تقارير التدقيق والتنظيف وخطة إعادة بناء التوثيق.

## مداخل التوثيق الأساسية
- API: `hesba-api-v1/README.md`
- Web Dashboard: `hesba-dashboard/README.md`
- Mobile Dashboard: `hesba-dashboard-mobile/README.md`

## حالة التوثيق
التوثيق ما زال تحت إعادة بناء تدريجية. الأولوية الآن للدقة والحد الأدنى الموثوق، وأي أجزاء غير مؤكدة تُوسم كـ "قيد الاستكمال".

لمتابعة سجل التنظيف وإعادة البناء:
- `study-docs/01_docs_cleanup_audit.md`
- `study-docs/04_active_docs_rebuild_plan.md`
- `study-docs/05_active_docs_index.md`
